# Quá trình push 1 images lên Registry nội bộ
## 1. Xác định thông tin registry
- Giả sử registry của bạn có domain là `registry.internal.local` và chạy ở cổng `5000` (ví dụ). Bạn cần biết:
- Hoặc là không cần Port:

- Domain/IP: `registry.internal.local`
- Port: `5000` (nếu có)
- Có dùng HTTPS hay không (registry tự ký cert hay HTTP thuần)

## 2. Nếu registry dùng HTTP hoặc cert tự ký (self-signed) — cấu hình Docker cho phép "insecure registry" 
- Bình thường là không cần đâu vì bạn có mạng nội bộ với cấu hình etc host là đủ rồi nhưng cứ lưu lại cho chắc

Đây là bước hay bị bỏ sót và gây lỗi `http: server gave HTTP response to HTTPS client` hoặc `x509: certificate signed by unknown authority`.
- Sửa file cấu hình:
```bash
sudo nano /etc/docker/daemon.json
```
- Thêm nội dung:
```bash
{
  "insecure-registries": ["registry.internal.local:5000"]
}
```
- Sau đó khởi động Docker:
```bash
sudo systemctl restart docker
```
## 3. Đăng nhập vào Registry
```bash
docker login registry.internal.local:5000
```
- Kiểm tra images hiện có:
```bash
docker images
```
- Xác định images bạn muốn: `myapp:latest`
- Gắn tag (tag) image theo đúng định dạng registry
```bash
docker tag myapp:latest registry.internal.local:5000/myapp:latest
```
- Cú pháp chung:
```bash
docker tag <image_gốc>:<tag> <registry_domain>:<port>/<tên_repo>:<tag>
```

## 4. Push image lên registry
```bash
docker push registry.internal.local:5000/myapp:latest
```
