# Quản trị Database
- Trong Container khi ta nhập sai địa chỉ email nó rất khó để khôi phục và kiểm tra 
- Note lại một số lệnh sau:
- kb-cloud là nơi bạn chạy docker compose
```bash
cd ~/kb-cloud

docker compose exec -T postgres psql -U user -d outline -c "
SELECT
  u.id,
  u.email,
  u.name,
  u.role,
  u.\"teamId\",
  u.\"lastActiveAt\",
  u.\"lastSigninEmailSentAt\",
  u.\"suspendedAt\",
  u.\"deletedAt\",
  t.name AS team_name,
  t.\"guestSignin\"
FROM users u
JOIN teams t ON t.id = u.\"teamId\"
WHERE lower(u.email) = lower('nguyenngoctrung257@gmail.com');
"
```
- Kiểm tra tài khoản có bị gắn SSO không:
```bash
docker compose exec -T postgres psql -U user -d outline -c "
SELECT
  u.email,
  ap.name AS authentication_provider,
  ap.enabled,
  ua.\"lastValidatedAt\"
FROM users u
LEFT JOIN user_authentications ua ON ua.\"userId\" = u.id
LEFT JOIN authentication_providers ap
  ON ap.id = ua.\"authenticationProviderId\"
WHERE lower(u.email) = lower('nguyenngoctrung257@gmail.com');
"
```
- Cách đọc kết quả:
- Không có user: Outline giả vờ trả success nhưng không gửi email.
- deletedAt có giá trị: user đã bị xóa mềm và không được tìm thấy trong luồng đăng nhập.
- suspendedAt có giá trị: tài khoản bị đình chỉ.
- guestSignin = false: workspace đã tắt đăng nhập email.
- authentication_provider có giá trị và enabled = true: Outline không gửi email mà chuyển user sang SSO.
- lastSigninEmailSentAt thay đổi sau mỗi lần yêu cầu: email đã được đưa vào hàng đợi.
