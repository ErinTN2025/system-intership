# Lỗi IP
## Loại lỗi gặp phải
- Đã cấu hình Security groups: Inbound, Outbound.
- Không connect được tới Ip public.
- Cần phải check `ip a`: Xem đã đúng chưa.
```bash
ss -tulnp | grep ...
```
- Đặc biệt nhất là `ip r`.

`ip r` là viết tắt của `ip route`: nó hiển thị **bảng định tuyến** của server — tức khi server muốn gửi một gói tin tới đâu, Linux sẽ nhìn vào đây để quyết định gửi qua card mạng và gateway nào.

Lấy đoạn sau làm 1 ví dụ

```text
default via 10.10.0.1 dev ens8 metric 100
```

* `default`: route mặc định. Khi không có route cụ thể hơn cho IP đích, dùng route này.
* `via 10.10.0.1`: gửi gói tin cho gateway `10.10.0.1` xử lý tiếp.
* `dev ens8`: gửi ra card mạng `ens8`.
* `metric 100`: độ ưu tiên. Số càng nhỏ càng được ưu tiên.
* Đây là đường đi mặc định qua mạng private `10.10.x.x`.

```text
default via 14.225.174.1 dev ens3 metric 100
```

* Cũng là route mặc định, nhưng đi qua card public `ens3`.
* Gateway `14.225.174.1` sẽ đưa traffic ra Internet.
* Server nên dùng route này khi trả lời client bên ngoài.

Vấn đề là: hai `default route` cùng `metric 100` nên Linux xem chúng ngang ưu tiên; việc Internet đi nhầm qua `ens8` là có thể xảy ra.

```text
10.10.0.0/16 dev ens8 proto kernel scope link src 10.10.3.139
```

Đây là route nội bộ tự sinh khi bạn gán `10.10.3.139/16` cho `ens8`.

* `10.10.0.0/16`: toàn bộ dải từ `10.10.0.0` đến `10.10.255.255`.
* `dev ens8`: muốn tới máy nào trong dải này thì gửi thẳng qua `ens8`.
* `proto kernel`: Linux kernel tự tạo, không phải bạn tự thêm.
* `scope link`: mạng cùng lớp 2/cùng subnet, không cần đi qua gateway.
* `src 10.10.3.139`: Nếu chính server này tạo ra một packet và kernel quyết định gửi packet đó qua route này, thì `10.10.3.139` là source IP ưu tiên mà kernel sẽ chọn. 

```text
14.225.174.0/23 dev ens3 proto kernel scope link src 14.225.175.219
```

Tương tự nhưng dành cho public NIC:

* `/23` bao gồm `14.225.174.0` đến `14.225.175.255`.
* Vì vậy `14.225.175.219` và gateway `14.225.174.1` nằm cùng subnet.
* Các máy trong dải này có thể kết nối trực tiếp qua `ens3`.

```text
172.17.0.0/16 dev docker0 proto kernel scope link src 172.17.0.1
```

Đây là mạng Docker mặc định:

* `docker0` là bridge do Docker tạo.
* `172.17.x.x` chỉ để container và host Docker trao đổi với nhau.
* Không liên quan đến public IP hay private network cloud.

Quy tắc Linux dùng route là: **route cụ thể nhất thắng trước**, rồi mới so metric.

Ví dụ:

* Đi tới `10.10.3.50` → chọn `10.10.0.0/16 dev ens8`, không dùng default.
* Đi tới `14.225.174.1` → chọn `14.225.174.0/23 dev ens3`.
* Đi tới `8.8.8.8` → không khớp route nào cụ thể, nên dùng một trong hai dòng `default`.

Vì thế, giữ route `10.10.0.0/16 dev ens8` là để VM vẫn nói chuyện được với mạng nội bộ; chỉ bỏ `default via 10.10.0.1 dev ens8` để nó không bị dùng làm đường ra Internet.
