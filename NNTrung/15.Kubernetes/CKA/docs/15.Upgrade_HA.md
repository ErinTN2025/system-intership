# Upgrade cluster và high availability (roadmap tuần 7)

## Lý thuyết cốt lõi

Version skew giới hạn chênh lệch version giữa API server, kubelet, kubeadm và kubectl. Nâng cluster kubeadm theo từng minor version được hỗ trợ, control plane trước, worker sau. `cordon` ngăn Pod mới, `drain` evict workload có kiểm soát; PodDisruptionBudget (PDB) có thể chặn drain. HA cần nhiều control plane sau một endpoint cân bằng tải; stacked etcd dùng etcd trên control plane, external etcd dùng cụm riêng. Ba member etcd chịu mất một member vì vẫn còn quorum hai.

## Lab A: nâng cấp trên cluster VM

**Môi trường:** cluster kubeadm lab, snapshot và etcd snapshot trước khi đổi version. Chọn patch của minor kế tiếp dựa trên [tài liệu upgrade cho version đang chạy](https://kubernetes.io/docs/tasks/administer-cluster/kubeadm/kubeadm-upgrade/) và package repository tương ứng; không điền `latest` hoặc bỏ qua minor.

1. Ghi `kubectl version`, `kubectl get nodes`, `kubeadm version`, tình trạng workload thử; chạy `sudo kubeadm upgrade plan`.
2. Trên control plane: nâng gói `kubeadm` đúng target version, `sudo kubeadm upgrade apply <vTARGET>`, rồi nâng `kubelet`/`kubectl` theo hướng dẫn OS, restart kubelet. Xác nhận API và node.
3. Trên từng worker: `kubectl drain <NODE> --ignore-daemonsets --delete-emptydir-data`; nâng `kubeadm`, chạy `sudo kubeadm upgrade node`, nâng/restart kubelet; `kubectl uncordon <NODE>`.
4. Sau mỗi node, xác nhận `kubectl get nodes`, `kubectl get pods -A`, request qua Service thử. Ghi thời gian gián đoạn nếu có.

**Bài phụ:** đặt PDB `minAvailable` bằng số replica hiện tại của workload thử, quan sát drain bị chặn; giảm PDB phù hợp, drain lại và nêu tác động khả dụng. Không dùng `--disable-eviction` để lách PDB trong bài này.

## Lab B: thiết kế HA

Vẽ sơ đồ 3 control plane + 2 worker + load balancer: địa chỉ API endpoint, etcd member, failure domain. Trên VM lab đủ tài nguyên, triển khai theo hướng dẫn HA kubeadm và thử tắt một control plane; xác nhận `kubectl get nodes` vẫn hoạt động và etcd còn quorum. Nếu không đủ máy, làm bài thiết kế và mô phỏng quorum trên giấy, ghi rõ chưa kiểm chứng thực địa.

**Đạt khi:** log version từng bước, không bỏ minor, worker được uncordon, workload còn hoạt động; giải thích được vì sao 2 member etcd không chịu được mất một. Xem [nguồn upgrade/HA](29.Tai_lieu_tham_khao.md#cka-cluster-và-control-plane).
