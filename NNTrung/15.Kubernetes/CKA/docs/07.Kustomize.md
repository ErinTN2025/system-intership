# Kustomize: base, overlay, patch, image transformation

## Lý thuyết cốt lõi

Kustomize tạo manifest cuối từ các YAML gốc mà không sửa trực tiếp chúng. **Base** chứa cấu hình chung; **overlay** tham chiếu base và chỉ khai báo khác biệt của môi trường. `resources` nạp manifest hoặc kustomization khác. `patches` sửa một hoặc nhiều resource; nên chỉ rõ `target` để tránh sửa nhầm. `images` thay image name/tag/digest mà không phải chép lại Deployment. `kubectl kustomize <dir>` chỉ render; `kubectl apply -k <dir>` gửi kết quả lên API server. Kustomize tích hợp trong `kubectl` có thể khác phiên bản CLI độc lập.

## Lab: dựng base và overlay

Yêu cầu: shell Bash và `kubectl`. Tạo cây thư mục:

```text
kustomize-lab/
  base/{deployment.yaml,service.yaml,kustomization.yaml}
  overlays/dev/kustomization.yaml
  overlays/prod/{kustomization.yaml,replicas.yaml}
```

```bash
mkdir -p kustomize-lab/base kustomize-lab/overlays/dev kustomize-lab/overlays/prod
cat > kustomize-lab/base/deployment.yaml <<'EOF'
apiVersion: apps/v1
kind: Deployment
metadata:
  name: web
spec:
  replicas: 1
  selector:
    matchLabels:
      app: web
  template:
    metadata:
      labels:
        app: web
    spec:
      containers:
      - name: nginx
        image: nginx:1.25
        ports:
        - containerPort: 80
EOF
cat > kustomize-lab/base/service.yaml <<'EOF'
apiVersion: v1
kind: Service
metadata:
  name: web
spec:
  selector:
    app: web
  ports:
  - port: 80
    targetPort: 80
EOF
cat > kustomize-lab/base/kustomization.yaml <<'EOF'
resources:
- deployment.yaml
- service.yaml
EOF
cat > kustomize-lab/overlays/dev/kustomization.yaml <<'EOF'
resources:
- ../../base
namespace: kustomize-dev
nameSuffix: -dev
images:
- name: nginx
  newTag: '1.27'
EOF
cat > kustomize-lab/overlays/prod/replicas.yaml <<'EOF'
apiVersion: apps/v1
kind: Deployment
metadata:
  name: web
spec:
  replicas: 3
EOF
cat > kustomize-lab/overlays/prod/kustomization.yaml <<'EOF'
resources:
- ../../base
namespace: kustomize-prod
nameSuffix: -prod
images:
- name: nginx
  newTag: '1.27'
patches:
- path: replicas.yaml
  target:
    group: apps
    version: v1
    kind: Deployment
    name: web
EOF
kubectl kustomize kustomize-lab/overlays/dev
kubectl kustomize kustomize-lab/overlays/prod
```

Trong output, dev có `web-dev`, 1 replica và nginx `1.27`; prod có `web-prod`, 3 replica và cùng image. Kiểm tra Service selector vẫn trỏ vào Pod labels. Tạo namespace trước khi apply vì trường `namespace` không tự tạo Namespace:

```bash
kubectl create namespace kustomize-dev
kubectl create namespace kustomize-prod
kubectl apply -k kustomize-lab/overlays/dev
kubectl apply -k kustomize-lab/overlays/prod
kubectl -n kustomize-prod rollout status deployment/web-prod
kubectl -n kustomize-prod get deployment web-prod -o jsonpath='{.spec.replicas}{"\n"}{.spec.template.spec.containers[0].image}{"\n"}'
```

Nếu `kubectl kustomize` báo patch không khớp, kiểm tra `group/version/kind/name` của resource **trước** khi áp `nameSuffix`. Nếu Pod không nhận lưu lượng, so `Service.spec.selector` với `Deployment.spec.template.metadata.labels` của bản đã render.
