## 1. Khái niệm GitOps
Argo được xây dựng dựa trên triết lý GitOps:
- Git repo là nguồn sự thật duy nhất (single source of truth) mô tả trạng thái mong muốn của hệ thống (desired state).
- Một agent (ArgoCD) liên tục so sánh trạng thái thực tế trên K8s cluster với trạng thái khai báo trong Git, nếu khác nhau thì tự đồng bộ (sync).
- Khác với CI/CD truyền thống (push-based: pipeline tự đẩy code vào cluster), GitOps là pull-based: cluster tự kéo thay đổi về.
- Đây là khái niệm quan trọng nhất cần nhớ: "Push vs Pull deployment model".

## 2. Hệ sinh thái Argo
Argo không phải 1 công cụ, mà là một bộ (Argo Project) gồm 4 thành phần:
- **Argo CD**: Công cụ Continuous Delivery cho Kubernetes theo mô hình GitOps.
  - **Application**: một CRD (Custom Resource) mô tả app cần deploy (source repo, path, destination cluster/namespace).
  - **Sync**: hành động đồng bộ trạng thái cluster theo Git.
  - **Sync Policy**: manual hay automated sync
  - **Health Status**: Healthy/ Progressing/ Degraded/ Mising.
  - **App of Apps**: pattern quản lý nhiều Application bằng 1 Application cha.
  - **Diff**: so sánh live state vs desired state trước khi sync.
- Argo Workflows:
  - Engine chạy workflow (pipeline) dạng container-native trên Kubernetes, định nghĩa bằng CRD `Workflow` (YAML), mỗi bước là 1 pod.
  - Dùng cho: CI pipeline, xử lý dữ liệu (data pipeline/ETL), ML pipeline.
  - Khái niệm cần nhớ: DAG (Directed Acyclic Graph) hoặc Steps để định nghĩa thứ tự các bước; Template (tái sử dụng); Artifact passing giữa các bước.
- Argo Rollouts
  - Bổ sung cho Kubernetes Deployment để hỗ trợ các chiến lược deploy nâng cao:
    - **Canary deployment**: đẩy dần traffic sang version mới.
    - **Blue-Green deployment**: chạy song song 2 version, chuyển traffic tức thì.
  - Lưu ý quan trọng: Progressive Delivery, Analysis (metrics-based) để tự động rollback nếu version mới có lỗi (dựa vào Prometheus...).
- Argo Events
  - Hệ thống event-driven, trigger workflow/pipeline dựa trến sự kiện (webhook, message queue, S3, cron,...)
  - Khái niệm: **EventSource**, **Sensor**, **Trigger**
