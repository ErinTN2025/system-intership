# Node Affinity
Node Affinity = quy tắc nói với Kubernetes rằng Pod "ưu tiên" hoặc "bắt buộc" chạy trên những Node có label nào đó.
- Đặt label cho các node:
```bash
kubectl label node worker1 role=app
kubectl label node worker2 role=app
kubectl label node worker3 role=data
```

## 2. Cấu trúc tổng thể
```yaml
affinity
    nodeAffinity:
        preferredDuringSchedulingIgnoredDuringExecution:
```
- `preferred...` nghĩa là ưu tiên, chứ không bắt buộc
- Khác với:
```yaml
requiredDuringSchedulingIgnoredDuringExecution
```
- `required`: bắt buộc phải thoản điều kiện
- `preferred`: cố gắng thỏa điều kiện.
- `weight: 80`: trọng số ưu tiên là 80
- `matchExpression`: Lọc theo toán tử:
```yaml
matchExpressions:
    - key: <ten_label_key>
      operator: <In | NotIn | Exists | DoesNotExist>
      values: ["gia_tri_1", "gia_tri_2"]
```
tùy thuộc vào trường bên ngoài là Pod hay Node mà matchExpressions đưa ra phương pháp lọc tương ứng.

## Lưu ý quan trọng
Trong YAML, quy tắt dùng dấu gạch ngang: `-`
- Khi phần tử đó là một mục trong một danh sách (Array/ List) -> dùng dấu '-'
- Khi phần tử đó là một cặp tên: Giá trị (Key: value) đơn thuần hoặc là một tập hợp thuộc tính (Object / Map). -> không dùng.

Ví dụ:
- Khi bạn khai báo một thuộc tính duy nhất có tên rõ ràng:
```yaml
metadata:
    name: my-app
    namespace: default
```
- Dùng `-` khi một Key chứa nhiều item tập hợp lại:
```bash
containers:
    - name: nginx
      image: nginx:latest
    - name: sidecar
      image: busybox
```
- Một ví dụ khác:
```bash
spec:                       #  Object (chỉ có 1 spec) -> Không dùng '-'
  containers:               #  List (Pod có thể có nhiều container)
    - name: web-app         #  Phần tử thứ 1 của danh sách containers (có '-')
      image: nginx
      ports:                #  List (Container có thể mở nhiều port)
        - containerPort: 80 #  Phần tử thứ 1 của danh sách ports (có '-')
          protocol: TCP
        - containerPort: 443 #  Phần tử thứ 2 của danh sách ports (có '-')
          protocol: TCP
      env:                  #  List (Có thể khai báo nhiều biến môi trường)
        - name: ENV_TYPE    #  Phần tử thứ 1 của danh sách env (có '-')
          value: production
```
